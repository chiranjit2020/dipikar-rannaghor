## Why does this matter?

Equipment-এ একসাথে সব কিনে ফেললে capital আটকে যায় এবং কিছু জিনিস অব্যবহৃত পড়ে থাকে। আবার জরুরি জিনিস বাদ দিলে launch পিছিয়ে যায়। তাই **must-have এখন, বাকিটা পরে**।

## Concept

প্রতিটি equipment-এর জন্য একই প্রশ্ন করো:

```
কেন দরকার?
কখন কিনব? (launch-এর আগে / পরে)
কী specification দেখব?
Approximate budget (Example — নিজের বাজারে যাচাই)
Alternative / সস্তা বিকল্প
Common mistake
Maintenance
```

### Must-have (launch-এর আগে)

| Item | কেন | Spec দেখো | Common mistake |
| --- | --- | --- | --- |
| Commercial burner / stove | মূল রান্না | Brass burner, ভালো flame control, LPG-rated | ঘরোয়া chullah দিয়ে commercial load চালানো |
| LPG (commercial) | জ্বালানি | Commercial connection + regulator + ISI hose | Domestic cylinder ব্যবহার (illegal + বিপজ্জনক) |
| Exhaust / chimney | ধোঁয়া, তাপ, প্রতিবেশী | Airflow (m³/hr) rating, baffle filter | Under-powered exhaust → গরম ও তেলচিটে kitchen |
| Refrigerator | Perishable storage | Litre capacity, দ্রুত recovery | ছোট fridge → বারবার বাজার, বেশি wastage |
| Work table (SS) | Prep surface | Stainless steel, শক্ত frame | কাঠ/plastic → hygiene fail |
| Storage rack | Dry store, FIFO | SS বা powder-coated, ভার বহন | মেঝেতে বস্তা রাখা → pest, নষ্ট |
| Weighing scale | Portion ও food cost | 0–5 kg (1 g) + 0–30 kg | Scale ছাড়া "আন্দাজে" — food cost অর্থহীন |
| Containers / bulk pots | রান্না ও store | Food-grade, ঢাকনাসহ | পাতলা ধাতু → পুড়ে যায় |
| Fire extinguisher | Safety + compliance | ABC / CO₂, kitchen-rated, servicing tag | মেয়াদ উত্তীর্ণ extinguisher |
| Knives, boards, ladles | Daily prep | Colour-coded board (veg/meat) | একই board সবকিছুতে |
| Hand-wash + sanitiser station | Hygiene | Separate sink, soap, sanitiser | Prep sink-এই হাত ধোয়া |

### Later (order বাড়লে)

Deep freezer, second burner, blast-cooling, dough machine, POS tablet stand, backup inverter/UPS, larger chimney।

## Cloud Kitchen Example

Dipikar Rannghor must-have তালিকা ধরে একটা sheet বানাবে — প্রতিটি item-এ budget, বিক্রেতা ২টি quote, must-have/later ট্যাগ। মোট must-have budget = setup capital-এর অংশ, যা Budget planning sheet-এ যাবে।

## Hands-on Task

1. উপরের must-have টেবিল নিজের menu অনুযায়ী কাটছাঁট করো (যেমন biryani হলে বড় হাঁড়ি + dum setup যোগ)।
2. প্রতিটি item-এ ২ জন local বিক্রেতা/online থেকে দাম নাও।
3. "must-have এখন" যোগফল বের করো → Budget sheet-এ বসাও।
4. "later" list আলাদা রাখো future roadmap হিসেবে।

## Common Mistakes

- Domestic LPG দিয়ে commercial চালানো — বেআইনি ও বিপজ্জনক।
- Exhaust কম শক্তির — সবচেয়ে বেশি regret করা সিদ্ধান্ত।
- Weighing scale বাদ দেওয়া — তখন food cost ও portion দুটোই আন্দাজ।
- একসাথে "সব" কিনে working capital শেষ করে ফেলা।
