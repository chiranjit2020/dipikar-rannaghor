## Why does this matter?

তুমি Cloud Kitchen সম্পর্কে অনেক video দেখতে পারো, অনেক blog পড়তে পারো — কিন্তু তাতে একটাও order আসে না। এই app-এর কাজ পড়া নয়, **তোমাকে বাস্তবে একটা Cloud Kitchen launch করতে বাধ্য করা।**

## Concept

**Dipikar Rannghor** হলো একটি hands-on documentation + execution system। প্রতিটি topic এই ছন্দে চলে:

```
WHY → WHAT → HOW → DO → VERIFY → DOCUMENT → TODO
```

অর্থাৎ প্রতিটি অধ্যায় শেষে তোমার হাতে থাকবে একটা **actual কাজ** (TODO), সেটা কীভাবে শেষ হয়েছে বোঝার **criteria**, আর কী **document** রাখতে হবে তার নির্দেশ।

App-টি দুটো progress আলাদা করে দেখায়:

- **Learning Progress** — কত documentation পড়া হয়েছে
- **Execution Progress** — বাস্তবে কত কাজ শেষ হয়েছে

কারণ একটা topic পড়া মানেই কাজ শেষ নয়।

## Real-world Example

ধরো তুমি "Competitor analysis important" — এটা পড়লে। এতে কিছুই বদলায় না।
কিন্তু যদি তুমি Zomato খুলে নিজের এলাকার ২০টা competitor-এর price, rating আর best-seller লিখে ফেলো — তাহলে তোমার হাতে একটা **market map** তৈরি হয়ে গেল। এই app সেই দ্বিতীয় জিনিসটা করায়।

## Cloud Kitchen Example

Dipikar Rannghor (সম্ভাব্য brand) — একটি residential area থেকে Zomato/Swiggy-তে ডেলিভারি-only রান্নাঘর। কোনো dine-in নেই, কম rent, কম staff — কিন্তু operations ও costing-এ কোনো ছাড় নেই।

## Hands-on Task

1. Settings-এ গিয়ে দেখে নাও data তোমার browser-এই (localStorage) থাকছে।
2. Dashboard-এ current phase আর milestone দেখো।
3. আজকের জন্য TODO থেকে সবচেয়ে উপরের **Critical** task-টা "In Progress"-এ নাও।

## Checklist

- [ ] App-এর ১০টা section একবার ঘুরে দেখা হয়েছে
- [ ] Learning vs Execution progress-এর পার্থক্য বোঝা হয়েছে
- [ ] প্রথম TODO বেছে নেওয়া হয়েছে

## Common Mistakes

- সব documentation আগে পড়ে ফেলা, তারপর কাজ শুরু করব — এই ভাবনা। ভুল। পড়া আর করা পাশাপাশি চলবে।
- Data cloud-এ আছে ভেবে নেওয়া। এখন এটা শুধু **এই browser-এ**। Settings থেকে regular backup export করো।

## Verification

Dashboard-এ Execution Progress ০% থেকে নড়েছে — মানে তুমি সত্যিই একটা কাজ ধরেছ।
