## Why does this matter?

Tool জানলে কাজ দ্রুত হয়। এই app-এর প্রতিটি অংশ একটা নির্দিষ্ট কাজের জন্য — সেটা জানলে তুমি রোজ খুলে **"আজ কী শিখব, আজ কী করব"** দুটোই এক নজরে বুঝবে।

## Concept

| Section | কীসের জন্য |
| --- | --- |
| **Dashboard** | তুমি কোথায় আছ — current phase, milestone, open/critical TODO, progress |
| **Documentation** | Phase-wise knowledge; প্রতিটি পাতা শেষে hands-on task |
| **Roadmap** | Business milestone M0–M11 এবং app-এর version roadmap |
| **TODO** | সব actionable কাজ — status, priority, phase, dependency |
| **Checklists** | Launch, opening, closing, compliance — tick-করা যায় |
| **Calculators** | Break-even ও Food Cost — নিজের সংখ্যা বসাও |
| **Glossary** | Business term সহজ বাংলায় |
| **Decision Log** | গুরুত্বপূর্ণ সিদ্ধান্ত + কারণ + তারিখ |
| **Resources** | Official portal-এর link (verify করার জন্য) |
| **Settings** | Data export/import, theme, language |

## How it works

- **Search** (উপরে / `Ctrl+K`) একসাথে documentation, TODO, checklist, glossary, calculator, decision খোঁজে।
- **Filters** — TODO ও Documentation-এ phase, category, status, priority দিয়ে ছেঁকে নাও।
- **Progress** — doc "Mark as read" করলে Learning Progress বাড়ে; TODO "Done" করলে Execution Progress বাড়ে।
- সব state তোমার browser-এ (localStorage)। অন্য device-এ sync হয় না — তাই Settings থেকে মাঝেমধ্যে **Export backup**।

## Hands-on Task

1. `Ctrl+K` চেপে "FSSAI" search করো — দেখো কোন কোন জায়গা থেকে result আসে।
2. TODO-তে গিয়ে filter: Priority = Critical। ওই কাজগুলোই আগে।
3. Settings → Export — ফাইলটা নিরাপদ জায়গায় রাখো।

## Common Mistakes

- Browser data clear করলে সব হারাবে — backup ছাড়া চলবে না।
- সব filter একসাথে লাগিয়ে "কিছু দেখাচ্ছে না" — filter reset করো।
