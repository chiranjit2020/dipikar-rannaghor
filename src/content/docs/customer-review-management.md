## Why does this matter?

Cloud Kitchen-এ rating সরাসরি order-এ রূপান্তরিত হয়। কম rating = কম visibility = কম order = আরও কম rating। এই লুপ ভাঙার একমাত্র উপায়: প্রতিটা negative signal-কে operational fix-এ পরিণত করা।

## Concept — কী track করবে

- **Rating trend** — সপ্তাহভিত্তিক গড়, নামছে না উঠছে
- **Reviews** — শুধু পড়া নয়, tag করা (দেরি / ঠান্ডা / portion / packaging / স্বাদ / ভুল item)
- **Complaints, refunds, cancellations** — সংখ্যা ও কারণ
- **Repeat order rate** — সবচেয়ে সৎ quality metric
- **Best ও poor performing item** — কোনটা বারবার নালিশ আনে

## Negative review → operational improvement

```
Review পড়ো
   ↓
Tag করো (দেরি / ঠান্ডা / portion / packaging / স্বাদ / ভুল)
   ↓
সপ্তাহে গুনে দেখো — কোন tag সবচেয়ে বেশি?
   ↓
সেই tag-এর জন্য SOP-তে একটা নির্দিষ্ট পরিবর্তন
   ↓
পরের সপ্তাহে ওই tag কমেছে কিনা যাচাই
```

উদাহরণ tag → fix:

| বারবার অভিযোগ | SOP fix |
| --- | --- |
| "ঠান্ডা এসেছে" | delivery radius ছোট করা; heat-retention packaging; handover time কমানো |
| "raita ছিল না" | Handover SOP-তে add-on tick + QC checklist |
| "কম দিয়েছে" | Cooking SOP-তে গ্রামে portion + plating scale |
| "দেরি" | prep par-level বাড়ানো; peak-hour roles; realistic prep time সেট |
| "leak করেছে" | packaging পাল্টানো; gravy আলাদা container |

## Responding to reviews

- সব review-এর উত্তর দাও — বিনয়ী, সংক্ষিপ্ত, defensive নয়
- Negative-এ: দুঃখ প্রকাশ + কী ঠিক করছ + আবার সুযোগ চাওয়া
- Positive-এ: ধন্যবাদ + specific কিছু উল্লেখ

## Cloud Kitchen Example

Dipikar Rannghor প্রতি রবিবার ১৫ মিনিট "review review": সপ্তাহের সব review tag করা, top tag বের করা, একটা SOP পরিবর্তন, পরের রবিবার যাচাই।

## Hands-on Task

1. একটা review-tracking sheet বানাও: তারিখ | platform | rating | tag | কী করলাম।
2. এখন পর্যন্ত সব review (নিজের বা competitor-এর mock হিসেবে) tag করে দেখো প্যাটার্ন পড়তে পারো কিনা।
3. একটা "review → SOP fix" টেবিল তৈরি করো (উপরেরটা নিজের ভাষায়)।
4. Weekly review-ritual ক্যালেন্ডারে রাখো।

## Checklist

- [ ] Review-tracking sheet তৈরি
- [ ] Tag তালিকা ঠিক করা (৬–৮টা)
- [ ] "Review → SOP fix" টেবিল
- [ ] Weekly review-ritual সেট
- [ ] Repeat order rate মাপার উপায় ঠিক করা

## Common Mistakes

- Review পড়ে খারাপ লাগা, কিন্তু tag/গোনা না করা।
- একটা রাগী review-তে overreact, প্যাটার্ন উপেক্ষা।
- Review-এর উত্তর না দেওয়া বা defensive উত্তর।
- Rating দেখা কিন্তু repeat rate না দেখা।

## Verification

তুমি বলতে পারছ "গত সপ্তাহে সবচেয়ে বেশি অভিযোগ ছিল ___ নিয়ে, তাই আমি SOP-তে ___ বদলেছি" — এবং পরের সপ্তাহে সেটা কমেছে কিনা দেখছ।
