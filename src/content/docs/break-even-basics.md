## Why does this matter?

Launch করার আগে তোমার জানা দরকার: "দিনে কতগুলো order না হলে আমি লোকসানে?" এই একটা সংখ্যা জানলে তুমি বুঝবে target বাস্তবসম্মত কিনা, নাকি model-ই বদলাতে হবে।

## Concept

**Break-even** = যেখানে মোট Contribution ঠিক মোট Fixed Cost-এর সমান। লাভ নেই, লোকসান নেই।

```
Contribution / order = AOV − Variable Cost / order

Break-even orders / month = Monthly Fixed Cost ÷ Contribution per order

Break-even orders / day   = (Break-even orders / month) ÷ চালু দিনের সংখ্যা

Break-even revenue / month = Break-even orders / month × AOV
```

- **Fixed Cost** — rent, base salary, internet, license amortization, minimum utility
- **Variable Cost / order** — food + packaging + platform commission + variable gas
- **AOV** — Average Order Value (combo/add-on দিয়ে বাড়ে)

## Worked Example (Hypothetical)

```
Monthly Fixed Cost              ₹40,000
AOV                             ₹230
Variable Cost / order           ₹150   (food ₹90 + packaging ₹12 + commission ₹48)
--------------------------------------------------
Contribution / order            ₹80
Break-even orders / month       40000 ÷ 80  = 500
Break-even orders / day (26 d)  500 ÷ 26     ≈ 19–20
Break-even revenue / month      500 × 230    = ₹1,15,000
```

মানে: দিনে ~২০টা order না এলে ওই মাসে লোকসান। এটা তোমার এলাকায় সম্ভব কিনা — সেটাই আসল প্রশ্ন।

## দুটো গুরুত্বপূর্ণ সত্য

1. **বেশি sales ≠ বেশি profit।** Contribution negative হলে যত বিক্রি, তত লোকসান।
2. **Discount দিয়ে order বাড়ানো আর profitable business এক নয়।** ₹230 AOV-তে ₹40 discount মানে contribution ₹80 → ₹40, break-even orders দ্বিগুণ।

## Common Mistakes

- Fixed cost-এ নিজের বেতন/সময়ের মূল্য না ধরা।
- Commission ও discount variable cost-এ না ধরা।
- এক-মাসের optimistic সংখ্যা ধরে পুরো পরিকল্পনা করা।
- Break-even ছোঁয়ার আগেই aggressive marketing খরচ করা।
