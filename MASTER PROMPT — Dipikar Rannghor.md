## ADDITION — Visual Theme & Storage Architecture

### Visual Theme

Use a **dark-first premium UI**, inspired by the overall visual feel of the CRED app, but **do not copy CRED's exact design**.

Requirements:

* Dark theme as the primary/default theme.
* Premium, minimal, elegant visual language.
* Use **Poppins** as the primary font.
* Typography should be **slightly larger than conventional web-app/dashboard font sizes** for better readability.
* Prefer generous spacing and comfortable line-height.
* Strong visual hierarchy between headings, body text, metadata, labels, and actions.
* Avoid overly dense dashboards and tiny text.
* Use subtle borders, depth, gradients, shadows, and micro-interactions only where they improve usability.
* The interface should feel **premium but practical**, not flashy.
* Maintain excellent readability on both desktop and mobile.
* Design mobile-first without making the desktop experience feel like an enlarged mobile UI.

### Storage & Deployment Strategy

The application should initially use:

**GitHub Pages + localStorage**

This is sufficient for the first MVP because the initial scope is primarily:

* Documentation
* Search
* Filters
* TODO management
* Checklists
* Progress tracking
* Basic user-side persistence

Do **not** introduce a backend unnecessarily at this stage.

However, design the application's data/storage layer with a clear abstraction so that `localStorage` can later be replaced or supplemented by **Supabase** without rewriting the core application logic.

### Planned Evolution

```text
Phase 1
GitHub Pages
      +
localStorage
      ↓
Documentation + TODO PWA

Phase 2
Vercel
      +
Supabase
      ↓
Authentication
Cloud Database
Multi-device Sync
Business Data
Analytics
      ↓
Full-fledged Cloud Kitchen Business Tracker
```

Keep deployment and persistence concerns separated from the application/business logic from the beginning.

The current MVP must remain **simple, lightweight, and static-hosting friendly**, while being architecturally prepared for the future migration to **Vercel + Supabase**.
